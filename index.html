🔗 ฐานข้อมูลบริษัท (Google Sheet)

เชื่อมแล้ว ทุกเครื่องในบริษัทจะเห็นข้อมูลชุดเดียวกัน ได้แก่ รายการ โครงการ บัญชีโปรด และหมวดหมู่ รูปใบเสร็จจะถูกเก็บใน Google Drive

📦 แจกแอปให้ทุกคนในบริษัท

ดาวน์โหลดไฟล์แอปที่ใส่ URL และรหัสไว้ให้แล้ว ส่งไฟล์นี้ให้พนักงานทาง LINE หรืออีเมล เปิดแล้วเห็นข้อมูลบริษัททันที ไม่ต้องตั้งค่าเอง

▶ วิธีตั้งค่าครั้งแรก (ทำครั้งเดียว โดยเจ้าของ Sheet)
  1. เปิด Google Sheet ของบริษัท → เมนู ส่วนขยาย → Apps Script
  2. ลบโค้ดเดิมทั้งหมด วางโค้ดด้านล่าง แล้วแก้บรรทัด KEY เป็นรหัสบริษัทที่ต้องการ → กดบันทึก 💾
  3. กด ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → เลือกประเภท “เว็บแอป”
  4. “เรียกใช้ในฐานะ” เลือก ฉัน และ “ผู้มีสิทธิ์เข้าถึง” เลือก ทุกคน → กดทำให้ใช้งานได้ → อนุญาตสิทธิ์ (Sheet + Drive)
  5. คัดลอก URL ที่ลงท้ายด้วย /exec มาวางด้านบน ใส่รหัสบริษัท แล้วกด “บันทึกและเชื่อมต่อ”

🔁 ถ้าเคยใส่โค้ดเวอร์ชันเก่าไว้แล้ว: วางโค้ดใหม่ทับ → ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → กด ✏️ → เวอร์ชันเลือก “เวอร์ชันใหม่” → ทำให้ใช้งานได้ (ใช้ URL เดิมต่อได้) ข้อมูลรูปแบบเก่าจะถูกเก็บไว้ในแท็บ “รายการ (เก่า)” จากนั้นกด “ส่งรายการในเครื่องทั้งหมดขึ้น Sheet” 1 ครั้ง
